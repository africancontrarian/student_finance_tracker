About

Student Finance Tracker

A responsive, accessible vanilla HTML/CSS/JS web application designed to help students track their daily expenses, manage budgets, and gain insights into their spending habits.


Features

  • Add, edit, and delete financial transactions
  • Regex-powered search with match highlighting
  • Sort records by description, amount, category, or date
  • Dashboard with spending statistics and 7-day trend chart
  • Budget cap with real-time ARIA live alerts
  • Multi-currency support (ZAR, USD, EUR) with manual rates
  • JSON import/export with validation
  • Dark mode toggle
  • Fully keyboard-navigable and screen-reader friendly
  • Mobile-first responsive design (360px → 768px → 1024px+)
